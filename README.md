# fakephong - テクスチャによる疑似 Phong シェーディング サンプルプログラム

## 1. 概要

このプログラムは、プログラマブルシェーダ（GLSL）が普及する以前の固定機能パイプラインにおいて、**テクスチャマッピングを利用して Phong シェーディング（疑似 Phong シェーディング）を実現する** 手法を学ぶためのサンプルプログラムです。本プログラムは、以下のブログ記事の解説に対応して作成されたものです。

- [テクスチャを使った Phong シェーディング](https://tokoik.github.io/blog/opengl/2005/01/14/texture.html)

OpenGL の標準的なライティング（Gouraud シェーディング）では、頂点ごとに光線計算を行って色を補間するため、分割数の少ないポリゴンではハイライトが歪んだり消えたりしてしまいます。本プログラムでは、あらかじめハイライト（鏡面反射光）を焼き込んだテクスチャ（スフィアマップ／環境マップ）を動的に生成し、視点座標系の法線ベクトル（または反射ベクトル）を用いてマッピングすることで、滑らかで鋭い Phong シェーディング風のハイライト表現を実現しています。

## 2. ビルド方法

このプログラムは [CMake](https://cmake.org/) を用いてビルド環境を整えます。各 OS ごとにソースコードが置かれているディレクトリでターミナル（またはコマンドプロンプト）を開き、以下の手順を実行してください。

### 2.1 Windows (Visual Studio 2022 の場合)

1. コマンドプロンプトまたは PowerShell を開き、このプロジェクトのディレクトリに移動します。
2. 以下のコマンドを実行してビルドディレクトリを作成し、CMake で構成します。

   ```bat
   mkdir build
   cd build
   cmake .. -G "Visual Studio 17 2022"
   ```

3. 生成された `build` フォルダ内の `fakephong.sln` を Visual Studio で開きます。
4. ソリューションエクスプローラーで **fakephong** プロジェクトを右クリックし、「スタートアップ プロジェクトに設定」を選択します。
5. 「ローカル Windows デバッガー」をクリックするか、F5 キーでビルドおよび実行します。

### 2.2 macOS (Xcode の場合)

1. ターミナルを開き、このプロジェクトのディレクトリに移動します。
2. 以下のコマンドを実行してビルドディレクトリを作成し、Xcode 用のプロジェクトを生成します。

   ```sh
   mkdir build
   cd build
   cmake .. -G Xcode
   ```

3. 生成された `build/fakephong.xcodeproj` を Xcode で開きます。
4. 実行スキームが **fakephong** になっていることを確認します。
5. 「Run」ボタン（再生ボタン）をクリックするか、Command + R でビルドおよび実行します。

### 2.3 Ubuntu Linux

1. ターミナルを開き、このプロジェクトのディレクトリに移動します。
2. 必要なパッケージ（`freeglut3-dev` など）がインストールされていることを確認し、以下のコマンドでビルドします。

   ```sh
   mkdir build
   cd build
   cmake ..
   make
   ```

## 3. 使い方

### 3.1 プログラムの起動方法

- **Windows**: `build\Debug\fakephong.exe`
- **macOS**: `open build/Debug/fakephong.app` または Xcode から Run
- **Ubuntu Linux**: `cd build && ./fakephong`

### 3.2 操作方法

- **マウスの左ボタンでドラッグ**: 画面内のオブジェクト（球、トーラス、ティーポット等）を 3 次元的に回転
- **マウスの右ボタンをクリック**: ポップアップメニューを表示し、描画モデルやマッピングモードを切り替え
- **キーボードの q, Q または ESC キー**: プログラムを終了

## 4. 解説

### 4.1 疑似 Phong シェーディングの原理

Phong の反射モデルにおける鏡面反射光強度 $I_s$ は、法線ベクトル $\mathbf{N}$、光源への方向ベクトル $\mathbf{L}$、視線方向ベクトル $\mathbf{V}$ から求まる中間ベクトル $\mathbf{H} = \frac{\mathbf{L} + \mathbf{V}}{\|\mathbf{L} + \mathbf{V}\|}$ を用いて計算されます。

固定機能のテクスチャ環境マッピング機能（`GL_SPHERE_MAP`）を利用すると、視点座標系における法線ベクトル $\mathbf{N} = (n_x, n_y, n_z)$ に基づいてテクスチャ座標 $(s, t)$ が自動生成されます。

$$s = \frac{n_x}{2} + \frac{1}{2}, \quad t = \frac{n_y}{2} + \frac{1}{2}$$

テクスチャ画像上にあらかじめ中間ベクトル $\mathbf{H}$ とのなす角に応じた輝度分布を焼き込んでおくことで、テクスチャ参照によってピクセル単位の鏡面反射ハイライトが得られます。

### 4.2 テクスチャの生成 (`init()` 関数)

`makeTexture()` 関数により、テクスチャ配列 `texture[TEXHEIGHT][TEXWIDTH][4]` に球面上の法線と光源方向 $\mathbf{L}$、視線方向 $\mathbf{V}$ から計算したハイライトパターンを書き込み、`glTexImage2D()` で 2D テクスチャとして GPU に転送します。
